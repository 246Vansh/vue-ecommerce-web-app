🛒 Vue E-Commerce Frontend Application

A frontend-only e-commerce web application built using Vue.js to demonstrate responsive UI design, component-based architecture, and dynamic client-side functionality.
This project focuses on creating a smooth and interactive shopping experience using modern frontend development practices.

🚀 Features

Dynamic product listing with filtering, sorting, and pagination
Product detail page with image gallery and interactive UI
Shopping cart functionality (add, remove, update quantity)
Real-time cart total calculations on the client side
Responsive design for desktop and mobile devices
Reusable and modular UI components
Clean and intuitive user interface

🛠 Tech Stack

Frontend: Vue3, JavaScript(ES6+), TalwindCSS
Tools & Platforms: Git & GitHub, Browser DevTools

⚙️ How It Works

Vue.js handles dynamic rendering and state management Products and cart logic are managed on the client side
UI updates reactively based on user interactions Responsive layout adapts across screen sizes

🧠 Learning Outcomes

Practical experience with Vue.js component architecture Strong understanding of client-side routing and state handling
Hands-on practice with responsive UI design Improved frontend performance optimization skills
